# Student Squares

Module 1 project for the [D3 ❤️ React course](https://www.react-graph-gallery.com/react-d3-dataviz-course):
a horizontal barplot of the course's first cohort by country, where every student is one square.

D3 does the math (`scaleBand`, `scaleLinear`), React renders the SVG.

Live: <https://j-sirgo.github.io/student-squares/>

## Run

```sh
npm install
npm run dev
```

## Deploy

```sh
npm run deploy
```

Builds to `dist/` and pushes it to the `gh-pages` branch.
